# Online Game Server API

Backend-сервис на базе Spring Boot для обеспечения работы игровой логики, управления пользователями с JWT аутентификацией
(access + refresh токены), ролевой моделью доступа (PLAYER, ADMIN) и транзакционной бизнес-логикой

## Технологический стек

* **Framework:** Spring Boot 3.x (Web, Data JPA, Security)
* **Language:** Java 17+
* **Database:** PostgreSQL
* **Monitoring:** Prometheus & Grafana
* **CI/CD:** GitHub Actions

## Документация API

### Аутентификация
| Метод  | Эндпоинт             | Описание                    | Доступ |
|:-------|:---------------------|:----------------------------| :--- |
| `POST` | `/api/auth/login`    | Авторизация и получение JWT | Public |
| `POST` | `/api/auth/register` | Регистрация и получение JWT | Public |
| `POST` | `/api/auth/refresh`  | Обновление токенов          | Public |
| `POST` | `/api/auth/logout`   | Выход из системы            | Public |

### Пользователь
| Метод  | Эндпоинт               | Описание                          | Доступ     |
|:-------|:-----------------------|:----------------------------------|:-----------|
| `GET`  | `/api/user/me`         | Получение профиля текущего игрока | User + JWT |
| `GET`  | `/api/user/me/inventory`| Просмотр всех карт в инвентаре    | User + JWT |

### Игровые карточки
| Метод  | Эндпоинт             | Описание                          | Доступ              |
|:-------|:---------------------|:----------------------------------|:--------------------|
| `POST` | `/api/cards/create`  | Создание новой игровой карты      | **ADMIN** + JWT     |
| `GET`  | `/api/cards/{id}`    | Получение деталей карты по UUID   | User + JWT          |
| `GET`  | `/api/cards`         | Получение списка всех карт        | User + JWT          |

### Игровые кейсы
| Метод  | Эндпоинт             | Описание                          | Доступ |
|:-------|:---------------------|:----------------------------------|:-------|
| `POST` | `/api/cases/create`  | Создание нового кейса             | **ADMIN** + JWT |
| `GET`  | `/api/cases/{id}`    | Получение данных кейса по UUID    | User + JWT   |
| `GET`  | `/api/cases`         | Список всех доступных кейсов      | User + JWT   |
| `POST` | `/api/cases/{id}/open`| Открытие кейса пользователем     | User + JWT   |

### Игровая логика
| Метод  | Эндпоинт                 | Описание                            | Доступ |
|:-------|:-------------------------|:------------------------------------|:-------|
| `POST` | `/api/game/click`        | Обработка клика и начисление дохода | User + JWT   |
| `POST` | `/api/game/sell/{id}`    | Продажа карты пользователя          | User + JWT   |

## Мониторинг

В проект интегрированы инструменты для отслеживания состояния системы:
* **Metrics:** Приложение экспортирует метрики в формате Prometheus по эндпоинту `/metrics`
* **Grafana:** Используется для визуализации метрик
